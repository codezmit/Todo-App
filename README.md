# Todo-App

A simple and intuitive todo application to help you organize and manage your daily tasks efficiently.

## Features

- ✅ **Create Tasks** - Easily add new tasks to your todo list
- ✏️ **Edit Tasks** - Modify existing tasks anytime
- 🗑️ **Delete Tasks** - Remove completed or unwanted tasks
- ✔️ **Mark Complete** - Check off tasks as you complete them
- 💾 **Persistent Storage** - Your tasks are saved locally
- 🎨 **Clean UI** - User-friendly interface for better task management

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/codezmit/Todo-App.git
cd Todo-App
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open your browser and navigate to `http://localhost:3000`

## Usage

1. **Add a Task** - Type your task in the input field and click "Add" or press Enter
2. **Complete a Task** - Click the checkbox next to a task to mark it as complete
3. **Edit a Task** - Click the edit icon to modify the task description
4. **Delete a Task** - Click the delete icon to remove a task
5. **Filter Tasks** - View all, active, or completed tasks using the filter options
